# Terraform Deployment for Azure Data Factory Project

## Overview

This Terraform configuration sets up the necessary Azure infrastructure for the Azure Data Factory project, including:

- Resource Group
- Azure Data Factory instance

## Prerequisites

- [Terraform](https://www.terraform.io/downloads.html) installed
- [Azure CLI](https://docs.microsoft.com/en-us/cli/azure/install-azure-cli) installed and authenticated
